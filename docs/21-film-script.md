## How it is built

### 3:33 · `stack` · 30.5 s

*On screen: card: stack.*

> Under the hood. In the browser, CesiumJS: its voxel ray-marcher runs our own shader, and the faces are painted from the model's native levels. Behind it, a Python FastAPI server reads Copernicus's cloud stores chunk by chunk with xarray, derives density and sound speed with TEOS-10, and pairs every float with the model. INCOIS, Argo, gliders and fishing advisories arrive the same way. Nothing to install. It is a web page.
